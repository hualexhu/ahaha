# GlitchLab (app package)

The full documentation (usage, every effect and parameter, architecture, tests,
limitations, credits) is in the [repository README](../README.md).

```bash
npm install
npm run dev          # Vite dev server
npm run build        # static site → dist/
npm test             # unit tests (Vitest)
npm run test:e2e     # fixtures + build + Playwright
```
